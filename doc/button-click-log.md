# 화면 버튼 기능 및 클릭 로그 목록

모든 활성 버튼은 클릭 시 `trader.log`에 다음 형식으로 기록한다.

`[버튼클릭] 화면=... 경로=... 버튼=... 기능=... 대상=... 결과=클릭 접수`

화면에는 클릭 로그용 메시지를 별도로 표시하지 않는다. 동적으로 생성되는 종목·전략·주문 버튼도 같은 방식으로 기록하며, 종목코드나 주문·전략 ID는 `대상`에 남긴다.

## 국내주식 대시보드

| 영역 | 버튼 | 기능 |
|---|---|---|
| 운영 | 모의실행 전환, 자동승인 전환 | 주문 실행 방식과 자동승인 상태 변경 |
| 보유종목 | 보유종목 동기화, 새로고침, 전량 매도 요청 | 증권사 잔고 동기화·조회·전량매도 요청 |
| 전략조회 | 진단하기, 찾기, 전략 적용, 분석 시작 | 신호 진단, 후보 탐색, 전략 반영 및 분석 |
| 스케줄 | 정기 스케줄 저장, 전체 사이클 실행, 주문 실행, 로그 복사 | 자동매매 일정 저장·즉시 실행·로그 복사 |
| 주문 | 주문·보유 현행화, 주문 취소, 승인, 거절, 재처리 | 주문 원장 동기화와 승인 주문 처리 |
| 주문 일괄 | 재처리 일괄, 취소후재처리 일괄 | 선택 주문을 일괄 재처리 |
| 잔고 보정 | 증권사 잔고 기준 일괄 보정, 전체 불일치 해결 | 내부 원장을 실제 증권사 잔고에 맞춤 |
| AI·최적화 | 계산, 최적화, 일괄 승인대기 등록 | AI 비중과 최적 주문 계산·등록 |
| 성과 | 일별 성과, 월별 성과, 현금흐름 저장 | 기간별 성과 조회와 입출금 반영 |
| AI 전략 | 목록 새로고침, 스케줄 적용, 감사 새로고침, 자율 실행, 자가진화 | AI 전략 조회·적용·검토·실행 |
| 급락반등 | 분석, 실전 실행, 실시간 스캔, 설정 저장 | 급락반등 전략 분석과 실행 |
| 하이킨아시 | 분석, 실전 실행, 실시간 스캔, 설정 저장 | 하이킨아시 전략 분석과 실행 |
| 동적 행 버튼 | 승인요청, 매수, 귀속매도, 전량매도, 삭제, 상세, 성과 | 해당 종목·전략·주문 행의 기능 실행 |

## 미스톡 대시보드

| 영역 | 버튼 | 기능 |
|---|---|---|
| 보유·전략 | 새로고침, 전량 매도 요청, 진단하기, 찾기, 전략 적용 | 미국주식 잔고와 전략 분석·주문 요청 |
| 지표전략 | 저장/적용, 스캔 테스트 | 지표전략 설정 반영과 사전 스캔 |
| 스케줄 | daily_auto, analysis_only, execute 즉시 실행 | 선택 실행 모드로 스케줄 즉시 실행 |
| 승인 | 선택 승인, 선택 거절, 승인, 거절 | 선택 또는 개별 승인대기 주문 처리 |
| 관리주문 | 새로고침, 정정, 취소 | 미국주식 관리주문 조회·변경 |
| 운영·진단 | 운영실, 진단, 인사이트 새로고침 | 운영 상태와 계좌·시장 진단 갱신 |
| 전략 워크벤치 | 분석 실행, 주문 사이클, 감사 새로고침 | 전략 분석·주문·감사 실행 |
| 성과·AI | 기간별 성과, 동기화, 비중 계산, 최적화 | 성과 조회와 AI 포트폴리오 계산 |
| 동적 행 버튼 | 적용, 자동검증, 상세, 자가진화, 백테스트, 승인, 폐기, 삭제 | 해당 전략·후보·주문 행 처리 |

## 기타 화면

| 화면 | 버튼 | 기능 |
|---|---|---|
| AI 스톡 | 새로고침, AI 분석 실행, 위험 검증 후 계획 생성, 탭, 닫기 | AI 후보 분석·검증·실행계획 관리 |
| 내러티브 모멘텀 | 자동 실행, 뉴스 자동생성, 스캔, 후보저장, 이력 저장, 스케줄 저장 | 뉴스 기반 전략 수집·분석·저장·예약 |
| 환경설정 | 온라인 차단, DB·캐시 초기화, 다시 불러오기, 저장, 설정 탭 | 운영 환경 조회·변경·초기화 |
| FinRL | Generate | 보유종목 기반 FinRL 배분안 계산 |
| 벤더 | 화면 내 탐색·실행 버튼 | 연동 도구 정보 조회 및 화면 이동 |
| 공통 | 상위 탭, 하위 탭, 정렬, 새로고침, 상세, 닫기 | 화면 전환·정렬·조회·대화상자 제어 |

정적 HTML 기준 버튼은 국내주식 84개, 미스톡 63개, AI 스톡 9개, 내러티브 16개, 환경설정 4개, FinRL 1개로 총 177개다. 테이블 행에 생성되는 동적 버튼은 개수와 관계없이 이벤트 위임으로 모두 기록한다.
