# Kiwoom 시장 국면 개선 진행률

이 문서는 `/home/ubuntu/hanstock_kw`에만 적용하는 시장 국면 수집·판정·대시보드 개선의 검증 상태를 관리한다. `_ora` 인스턴스는 범위에서 제외한다.

## 완료율 산정

| 영역 | 비중 | 완료 조건 | 현재 |
|---|---:|---|---:|
| Kiwoom 지수 수집 | 15% | KOSPI·KOSDAQ 260거래일 수집 및 검증 | 15% |
| 시장 폭 수집 | 15% | 고정 60종목의 상승률·SMA20/60 상회율 산출 | 15% |
| 품질·대체 정책 | 10% | good/degraded/insufficient와 신규 위험 차단 | 10% |
| 완전 국면 분류 | 10% | 유효 입력에서 unknown 없는 결정적 분류 | 10% |
| 영속화·이력 | 10% | 국면·근거·품질·신뢰도·위험 배율 저장 및 조회 | 10% |
| API·수동 갱신 | 10% | current/history/diagnostics/refresh 제공 | 10% |
| 대시보드 | 15% | 상태·지수·시장 폭·근거·체크리스트·30일 이력 | 15% |
| VM 사전 점검 | 5% | 평일 08:43 KST `_kw` 전용 실행 | 5% |
| 전략 실행 연계 | 5% | 저장 국면 우선 사용, 불충분·노후 데이터 fail-closed | 5% |
| 검증·운영 확인 | 5% | 로컬 전체 검증과 VM 배포 후 실제 상태 확인 | 4% |

현재 개발 완료율은 **99%**다. 남은 1%는 VM 배포 후 다음 실제 거래일의 08:43 자동 수집, DB 저장, 대시보드 표시까지 이어지는 운영 증적이다.

## 안전 불변조건

- 시장 국면 수집은 조회 API만 사용하며 주문 API를 호출하지 않는다.
- 일반 대시보드 조회는 저장된 DB 결과만 사용한다. Kiwoom 재수집은 명시적 갱신에서만 수행한다.
- 데이터가 insufficient이거나 오래됐으면 신규 위험을 차단한다.
- `.env`, 계좌번호, 원문 인증 응답은 저장하거나 화면에 표시하지 않는다.
- `_ora` 저장소, cron, DB, 서비스는 변경하지 않는다.
