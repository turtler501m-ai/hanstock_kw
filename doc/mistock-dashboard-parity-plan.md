# 미스톡 대시보드 한스톡 기능 이식 계획

## 목표와 원칙

미스톡 대시보드의 기본 계좌·후보·승인·성과 기능은 유지하면서, 한스톡에서 이미
구현된 의사결정 추적, 관리 주문, 운영 진단, 정합성, 전략 운영 기능을 미국주식에
맞게 이식한다.

- 한스톡 공통 서비스와 저장소를 우선 재사용한다.
- 미스톡 거래 DB와 공통 AI DB의 데이터 출처를 화면에서 구분한다.
- 미국주식 가격의 소수점, USD/KRW 환율, 미국 거래시간을 보존한다.
- 주문 접수, 부분체결, 전량체결을 서로 다른 상태로 표시한다.
- 쓰기 기능은 승인, 멱등성, 리스크 검증이 연결된 뒤에만 활성화한다.
- 기존 지표전략, 주간 성과, 현금흐름, 전략 생명주기 기능은 중복 구현하지 않는다.

  - [ ] 요청수량, 체결수량, 지정가, 평균체결가

## 공통 기능 재사용 경계

즉시 조회 재사용이 가능한 한스톡 기능:

- `decision_pipeline_service.build_pipeline(market="US")`
- AI 실행계획, 전략결정, 관리주문, 전략 포지션 조회
- 위험 예약과 포지션 보호 조회
- 자동화 정책과 실행 이력 조회

선행 변경 없이 미스톡 주문 실행에 직접 연결하지 않는 기능:

- 정수 가격을 전제로 하는 공통 실행계획 변환
- 주문 접수 직후 거래를 저장하는 공통 주문 제출 함수
- 중앙 AI DB의 관리 주문을 미스톡 거래 DB의 주문 원장으로 사용하는 작업
- AI 후보 사후성과를 미스톡 실제 계좌성과로 대체하는 작업

## 검증 기준

- 신규 DOM ID와 API 경로의 프런트엔드 계약 테스트
- `market=US` 강제 및 데이터 출처 표시
- 빈 데이터, 부분 실패, stale 데이터 렌더링
- 승인 동시 실행 시 브로커 주문 1회
- 주문 접수 상태를 체결로 표시하지 않음
- 부분체결 수량만 보유·성과에 반영
- 미스톡 기존 탭과 전략 생명주기 회귀 없음
- 네트워크 호출 전부 mock
- `python -m unittest discover -s tests`
- `powershell -ExecutionPolicy Bypass -File tools/verify-local.ps1`
- `powershell -ExecutionPolicy Bypass -File tools/check-encoding.ps1`
