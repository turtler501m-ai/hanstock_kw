# Hanstock 운영 가이드

## 지원 범위

현재 애플리케이션은 키움 REST API를 통해 국내주식과 미국주식을 조회·주문합니다.
KIS, 해외선물, Telegram 수집기 및 QuantConnect 실행 경로는 지원하지 않습니다.

## 로컬 실행

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
copy .env.example .env
.\scripts\local\server.cmd restart
```

대시보드는 기본적으로 `http://127.0.0.1:8000`에서 확인합니다. 상태와 로그는
`scripts\local\server.cmd status|logs|tail` 명령으로 확인합니다.

## 거래 안전 설정

새 환경에서는 다음 값을 유지합니다.

```dotenv
DOMESTIC_STOCK_BROKER=kiwoom
KIWOOM_TRADING_ENV=demo
TRADING_ENV=demo
DRY_RUN=true
ENABLE_LIVE_TRADING=false
REQUIRE_APPROVAL=true
```

실계좌 주문은 거래 환경 일치, `DRY_RUN=false`, `ENABLE_LIVE_TRADING=true`를 모두
요구합니다. 자율매매는 별도의 실거래 활성화와 opt-in 안전 경계도 통과해야 합니다.
계좌번호와 API 자격증명은 로컬 또는 VM의 `.env`에만 보관하고 커밋하지 않습니다.

## 검증

```powershell
powershell -ExecutionPolicy Bypass -File tools\verify-local.ps1
python tools\run-tests.py --profile all --timeout 180
powershell -ExecutionPolicy Bypass -File tools\check-encoding.ps1
```

전체 테스트는 모듈을 배치로 나누어 실행하므로 단일 `unittest discover`보다 오래
걸릴 수 있습니다.

## 배포

배포는 깨끗한 로컬 브랜치에서 `.\scripts\local\deploy-vm.ps1`로 수행합니다.
VM의 소스를 직접 수정하지 않습니다. Python 의존성은 지원 범위를 나타내는
`requirements-*.txt`와 정확한 배포 버전인 `constraints-deploy.txt`로 관리합니다.

```powershell
pip install -c constraints-deploy.txt -r requirements.txt
```

## 생성 데이터

런타임 상태는 `.runtime/`, 로그는 `logs/`, 시장·거래 데이터는 `data/`에만 둡니다.
`__pycache__`, 데이터베이스, 로그 및 `.env`는 Git에 추가하지 않습니다.
