# 현재 구조 및 복사 분석

작성일: 2026-08-14

## 목표

기존 Hanstock 저장소에서 다음 화면과 동작을 별도 저장소로 옮긴 후 국내주식과
미국주식 증권사 연동을 한국투자증권(KIS)에서 키움증권 REST API로 단계적으로
전환한다. 최초 운영 목표는 두 시장 모두 모의투자이며 실전투자는 후속 범위다.

- 한스톡 국내주식 대시보드 (`/`)
- 미스톡 미국주식 대시보드 (`/mistock`)
- 환경설정 대시보드 (`/env-settings`)

## 최초 복사 범위

- `src/`: 대시보드 실행과 거래·저장소·전략 의존성
- `web/`: 템플릿, CSS, JavaScript, 정적 자산
- `config/`: 비밀이 아닌 설정과 종목 메타데이터
- `tests/`: 기준 동작 보존을 위한 테스트
- `tools/`, `scripts/local/`: 로컬 검증과 대시보드 실행 도구
- 루트 환경 예제, 요구사항, 실행·검증 파일

복사 제외 대상은 `.env`, `.runtime/`, `data/`, `logs/`, Android 앱, IDE 설정 및
VM 로컬 상태다.

## 발견된 결합 구조

1. 국내주식 API가 `src/trader.py`와 `src/api/kis_api.py`에 중복 구현되어 있다.
2. 전략과 대시보드가 `rt_cd`, `output1`, `pdno`, `hldg_qty` 등 KIS 원본 응답
   필드를 직접 사용한다.
3. `src/dashboard/core.py`가 국내주식 이외의 선물·QuantConnect 서비스도 import한다.
4. `src/dashboard/__init__.py`가 모든 라우트를 한 번에 등록한다.
5. 미스톡 역시 KIS 미국주식 클라이언트와 KIS 원본 응답 형식에 결합되어 있어
   국내주식과 별도의 키움 미국주식 adapter 및 화면 연동이 필요하다.

따라서 최초 커밋은 실행 가능한 기준선을 보존하기 위해 일부 비대상 Python 모듈을
포함한다. 이후 라우트와 서비스 경계를 정리하면서 제거 가능 여부를 테스트로 확인한다.

## 전환 범위 기준

- 1차 전환: 한스톡 국내주식 KIS 연동을 키움 REST API 모의투자로 전환
- 2차 전환: 미스톡 미국주식 KIS 연동을 키움 REST API 모의투자로 전환
- 자격증명: 국내·미국 모의계좌의 계좌번호, App Key/Secret과 토큰을 분리
- 보류: 해외선물, Bybit, QuantConnect 및 Android
- 키움 전환 중에도 증권사 선택 설정과 KIS 롤백 경로를 유지
